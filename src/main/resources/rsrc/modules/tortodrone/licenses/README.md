# Third-party license texts

The portable release copies the dependency license texts from
[`src/main/resources/licenses`](../src/main/resources/licenses) into this
directory. The executable JAR also retains the upstream notices under
`META-INF/`.

See [dependency notices](../src/main/resources/THIRD-PARTY.md) for versions,
upstream links and SHA-256 hashes. Tortodrone's own license is in the repository
root, not in this directory.
